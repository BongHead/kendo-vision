# kendo-vision
Kendo strikes are hard to detect and judge by a machine. Let's see how far and precise we can go.\
Code skeleton generated by Claude Opus 5.5, so blame me instead for any bugs/bad code.\
Currently uses YOLOE to detect stuff, unless someone wants to start labeling frames.

## How to run
Python 3.12, NVIDIA GPU

### Setup:
```
py -3.12 -m venv .venv
.venv\Scripts\activate
pip install torch torchvision --index-url https://download.pytorch.org/whl/cu126
pip install -e .
```
doing `pip install -e .` alone on Windows installs the CPU build.\
have a heart attack because it just downloaded like 3 GB of dependencies and models.

### Run (via CLI): 
```
kendo-vision run --source data/raw/match.mp4 --show --save outputs/match.mp4 --events outputs/match.jsonl
kendo-vision run --source 0 --show --red-side right
```
(tatsukis are hard to tell, but you can just set `track.use_tasuki: true` in `configs/default.yaml` although it's not very accurate)\
Feel free to rename the output file names
